# JCash - E Wallet Simulation

A web application for simulating an E-Wallet 

## Features

- Auth using JWT
- Transaction fee logic
- Real time balance
- Transaction history tracking

## Tech Stack

- Node.js
- React*
- MySQL
- Kubernetes*

## Local Setup
- node
- express
- mysql2

```bash
node app.js
```

The app will be available at http://localhost:3000
